# Review checklist

Run the three scripts first (see `DESIGN.md`). Then:

## Look
- [ ] Colours come from tokens. One accent at a time.
- [ ] Abel for headings and big labels. Source Code Pro for body and small labels.
- [ ] Corners and spacing match the scale.
- [ ] Some texture, not flat fills.
- [ ] Logo centred with space, or left aligned with left text.

## Use
- [ ] Works on a phone at 16px side gutter. No sideways scroll.
- [ ] Controls are reachable by keyboard and have visible focus (sun colour).
- [ ] Text is readable on the dark ground. Hints are not the only way to find something.

## Sound
- [ ] Musical behaviour unchanged unless that was the request.
- [ ] Played it once with the sound on.

## Words
- [ ] Short sentences, no em dashes, none of the banned words.
- [ ] `manual.html` updated, with a dated "What's new" line, if behaviour changed.

## Tell Jim
- [ ] What changed, in plain English.
- [ ] What was not tested.
