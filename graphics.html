Using the SVGs in Figma

Drag an SVG onto a Figma page. Text stays live, boxes and rings are shapes, and the screenshots are images you can swap. Install Abel and Source Code Pro first (both are in design-assets/fonts and on Google Fonts). Each line of text is its own layer, so a paragraph that wraps is a few layers. Glows come in as blurred circles. The grain overlay is left out.
