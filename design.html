Into Figma

  1. Install the fonts. Download the kit and install the three .ttf files. Figma picks them up straight away (restart the desktop app if not).
  2. Bring in the mark. Drag the SVGs from logo/ onto the canvas. They stay as editable vectors, one path per building.
  3. Get editable screens. In Figma, run the html.to.design plugin and paste the app's address. It rebuilds the live page as frames with real text, colours and auto layout. Do the same for /manual and this page.
  4. Make the styles. Open the Tokens Studio plugin, choose Load from file, and pick tokens/tokens.json. It creates the colour and type styles in one go.
  5. Keep the screens nearby. The PNGs in screens/ are the app exactly as it is today, for reference while you redesign.
